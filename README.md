# 🎬 Netflix Clone (HTML & CSS)

A simple, responsive Netflix landing page clone built with pure HTML5 and CSS3. Perfect for learning responsive design, Flexbox, and CSS Grid.

---

## ✨ Features

- 🎥 Netflix-style dark UI with hero section
- 📱 Fully responsive (Mobile + Tablet + Desktop)
- 🎨 Clean layout with hover effects & smooth transitions
- 🔐 Sign-in button & footer links (UI only)
- 🖼️ Movie/TV show sections with thumbnail grids

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- No JavaScript or frameworks lightweight!
