🎬 Netflix Clone (HTML & CSS)

A simple Netflix landing page clone built using pure HTML and CSS. This project replicates the look and feel of Netflix's homepage, focusing on UI design and responsiveness.

🚀 Features
🎥 Netflix-style homepage UI
📱 Fully responsive design (Mobile + Desktop)
🎨 Clean and modern layout
🔥 Hero section with background image
📺 Movie/TV show sections (static UI)
🔐 Sign-in button (UI only)
🌐 Footer with links
🛠️ Technologies Used
HTML5
CSS3 (Flexbox & Grid)
